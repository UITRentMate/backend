# Authentication và User Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hoàn thành đăng ký, đăng nhập, làm mới token, đăng xuất và xem tài khoản theo contract đã được người dùng chốt.

**Architecture:** Giữ Route → Controller → Service → Prisma. Access token là JWT 1 giờ; refresh token ngẫu nhiên trong HttpOnly Cookie 7 ngày, chỉ lưu hash và xoay vòng qua bảng phiên. Mật khẩu hash bằng bcrypt.

**Tech Stack:** Express 5, TypeScript CommonJS, Prisma 6, PostgreSQL, bcrypt, jsonwebtoken, Node test runner.

**Spec:** `docs/auth-user-contract-draft.md`; bản gửi issue ở `docs/issues/7-auth-user-endpoint-proposal.md`.

## Global Constraints

- Không sửa các bảng nghiệp vụ hiện có ngoài relation User → phiên refresh; migration chỉ thêm bảng phiên.
- Không triển khai API xác minh Chủ trọ trong issue #8; register luôn tạo TENANT/ACTIVE.
- Không trả passwordHash, refresh token trong JSON hoặc log.
- Không stage/commit/push tự động theo `AGENTS.md`; yêu cầu tạo nhánh `feat/auth` đã được thực hiện.
- FE 1 chưa xác nhận contract; mọi điểm còn mở phải nêu rõ khi bàn giao.

## Review Focus

- Hai request refresh đồng thời không được cùng tạo phiên hợp lệ.
- Replay token đã xoay vòng phải thu hồi cả family.
- Account bị khóa sau khi cấp JWT không được truy cập `/users/me` hoặc refresh.
- Trùng email/phone do race trong database phải trả 409 đúng trường.
- Cookie phải có HttpOnly, path và hạn 7 ngày; không có token thô trong database.
